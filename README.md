# Portal Eletrica

Website com o intuito de realizar cálculos elétricos dos mais diversos ramos 

## Demostração

### Veja o site: [Clique aqui]()

## Propósito 

- Agilize seu serviço com a nossa calculadora e fique somente com o serviço manual

### MAPA

- index.html
-- quadrados com cores destacadas e ícones para cada tipo de cálculo 

- energiaSolar.html
--> Cálculo para quantidade de placas solares necessárias na instalação levando em conta consumo mensal, taxa de irradiação solar, rendimento e potência das placas escolhidas
--> para sistemas off-grid, dimensionar banco de baterias


- partidaMotor.html
--> Dimensionar equipamentos elétricos (disjuntor, relé, fusível e contatora) com base na corrente de partida do motor mono ou trifásico 

- residencial.html

-- Cálculo de projeto luminotécnico, incluindo quantidade de lâmpadas por cômodo com base na área, p.d. e lúmens da lâmpada 

-- cálculo de quantidade de tomadas por cômodo baseado no uso para ele

- tipoDeOnda

-- conversões Ca-Cc
